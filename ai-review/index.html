系统性回调 / AI硬件崩盘 / 14跌3涨
硬件主线 · 系统性崩盘
AI产业链系统性回调——17 赛道 14 跌 3 涨（CPO -10.54% / PCB -8.11% / 半导体设备 -5.97% / AI算力芯片 -4.97% 领跌，仅 AI应用 +0.12% / AI语料 +0.36% / AI手机 +0.06% 微红），龙头层面 1/10 收涨，中芯国际 +2.11% 独涨、中际旭创 -12.69% / 寒武纪 -10.81% 领跌；6 大核心板块当日成交额合计约 1917 亿（降级为成交额口径，无正负），资金在硬件崩盘中显著收缩、CPO单日成交702.63亿为唯一亮点，整体呈放量杀跌特征。
题材 · 防御抱团·玄学逆势

催化 · 缺位·外盘压制
当日AI产业链缺乏正向催化、呈无抵抗回调——前日文化传媒AI漫剧（海外短剧中国厂商占九席）的利好余温消退，题材全面退潮（华为概念 -5.59% / 钙钛矿 -7.59% / BC电池 -6.77%）；外盘科技走弱与分母端压制共振，科创50 -3.81%领跌、CPO单日 -10.54% 创本轮调整以来最大跌幅。流动性层面前序「支持资本市场工具/回购增持再贷款」利好已price-in，风险偏好由修复直接转向冰点，需等待新催化与止跌信号。
展开三大催化分组
海外映射（需求/供给硬支撑）
海外科技走弱与分母端压制共振——费城半导体指数承压、纳指回调，A股双创与AI硬件同步重挫（科创50 -3.81%领跌、CPO -10.54%）；映射偏负——AI硬件链（CPO/PCB/AI算力芯片）单日放量杀跌，中际旭创 -12.69% / 新易盛 -9.46% / 寒武纪 -10.81% 龙头齐挫，反映海外映射与全球AI资本开支预期边际走弱，短期需观察龙头能否止跌、HBM4/SEMI设备等中长期逻辑是否松动。
国产 / 产业 / 政策
扩大内需战略实施方案(2026-2030)预期支撑防御消费（酿酒+2.39%/船舶+2.18%/农林牧渔+1.55%）；国产替代逻辑下半导体制造相对抗跌（中芯国际+2.11%为10只核心龙头唯一收涨、北方华创-3.41%跌幅远小于CPO）。但前序"支持资本市场工具/股票回购增持再贷款优化"政策利好已price-in，系统性回调中政策托底信号暂缺，风险偏好转向冰点、连板高度降至4板、晋级率27.27%，纯情绪博弈（羊字辈玄学）成避险出口。
应用 / 数据要素 / 传媒
AI应用端相对抗跌——AI应用 +0.12%、AI语料 +0.36%、AI智能体 -1.95%、AIGC -3.65%、大模型 -3.55%，显著优于硬件（CPO -10.54%/PCB -8.11%）。文化传媒AI漫剧余温尚存（文投控股10天6板、浙文影业/大晟文化/龙版传媒/奥飞娱乐/电魂网络2连板），但前日"海外短剧中国厂商占九席、活跃用户超1.5亿"的催化动能衰减、题材分化，应用端强于硬件的格局延续但整体随大盘回落。
