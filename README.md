# ashare-review · A股 & 美股 每日复盘

A股与美股三个维度的每日收盘复盘报告，由定时任务自动生成并推送至 GitHub Pages。

## 永久访问地址（三合一 Tab 入口）

👉 **https://jqmreturning-art.github.io/ashare-review/**

地址永久不变，页面内通过 Tab 切换查看三份报告：

| Tab | 报告 | 更新频率 | 子目录直链 |
|---|---|---|---|
| 美股科技 | 美股科技板块日度复盘（隔夜全景/权重拆解/指数温度/利率流动性/龙头财报/产业催化/估值拥挤/A股映射） | 每美股交易日 07:00 | `./us-review/` |
| A股大盘 | A股收盘主线与情绪复盘（情绪温度/涨停梯队/板块强弱/主线研判） | 每交易日 15:01 | `./market-review/` |
| A股AI产业链 | A股AI产业链日度复盘（赛道排行/情绪温度/资金动向/龙头梯队/产业催化） | 每交易日 15:01 | `./ai-review/` |

## 文件结构

- `index.html` — 三合一 Tab 导航容器（固定，不随日报覆盖）
- `us-review/` — 美股科技报告（`index.html` 每日覆盖 + 日期归档）
- `market-review/` — A股大盘报告（`index.html` 每日覆盖 + 日期归档）
- `ai-review/` — A股AI产业链报告（`index.html` 每日覆盖 + 日期归档 + 成分股 Excel）

> 本报告为收盘静态快照，数据仅供参考研究，不构成任何投资建议。市场有风险，决策需独立判断。
